# Contributing

Thank you for your interest in contributing to FlowMouse! We appreciate you taking the time to help improve the project.

Please review the guidelines below before you start working on any changes.

## What kind of contributions are we looking for?

* **Bug Fixes & Minor Improvements:** We welcome small, focused pull requests that fix bugs, improve performance, or refine existing features.

* **New Features & Significant Changes:** We currently do not accept pull requests for major new features or significant changes. This is due to our limited review capacity and our need to comply with Chrome's [Single Purpose Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#quality_guidelines). However, you are welcome to discuss feature ideas via [Issues](https://github.com/Hmily-LCG/FlowMouse/issues), or fork the project to build custom features under the GPLv3 license.

## A note on AI-generated code

Mouse gestures interact with a wide range of complex web standards. Maintaining compatibility across different web pages (e.g. iframes, shadow DOMs or pages in quirks mode) requires careful manual consideration of edge cases.

Due to this complexity, AI tools often struggle to generate robust, production-ready code for this specific domain. **Therefore, we ask that you do not submit code that is entirely generated by AI without careful review.**
